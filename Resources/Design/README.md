# Verso visual identity

The selected Bookmark V icon uses a bold ivory V with a peach bookmark detail on a terracotta background.

- Terracotta: `#A84E39`
- Warm ivory: `#FFF2DF`
- Peach: `#EAB48C`

`verso-icon.svg` is the canonical vector artwork. `../Verso.icns` is the packaged macOS icon, rendered from that SVG at 16, 32, 128, 256, and 512 points with standard and Retina representations. Preserve the original geometry and colors when generating future platform assets.

Keep native macOS surfaces and semantic text colors. The icon palette is selected; custom interface accents are not yet applied.
